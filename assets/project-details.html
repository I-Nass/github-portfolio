Problem Statement & Context

High monthly software costs and heavy page loads prevent many underfunded schools from adopting digital learning. Basic LMS was built as a lightweight, subscription-free alternative designed to run on modest hardware and mobile devices without requiring expensive cloud infrastructure or technical staff.

System Capabilities

  • Independent Instance Deployment: Deployed each school instance using available free tiers across hosting and database providers, completely eliminating recurring software licensing costs.
  • Dual-Mode Connectivity (Online & Hotspot LAN): Engineered the application to run both as a standard cloud web app and locally over a teacher-hosted Wi-Fi hotspot, allowing lessons to proceed without internet.
  • Offline Lesson Caching (PWA & IndexedDB): Integrated Service Worker caching and browser IndexedDB so students can access and read lesson materials when disconnected.
  • Offline Quiz Outbox & Background Sync: Built client-side quiz submission queueing that stores responses offline and automatically synchronizes attempts once a connection is detected.
  • Live Classroom Whiteboard & Hotspot AirDrop: Implemented real-time interactive canvas drawing and local zero-data file broadcasting via WebSockets.
  • Subject & Lesson Hierarchy: Designed structured academic management (Classes, Subjects, Topics, Lessons) supporting direct study PDF attachments via MongoDB GridFS.
  • Email-Free Administration: Built in-app user and credential management so administrators and teachers can reset student passwords directly without email dependencies.
